# Historical benchmark claims — unverified

**Status: withdrawn from performance and accuracy claims.** The prior table and narrative asserted zero loss, 100% recovery, and broad binary coverage but did not provide reproducible commands, input identities or hashes, tool versions, or a measured method. Those assertions were not verified and must not be cited as project results.

No benchmark result is currently endorsed by this repository. The minimal PE fixture under `tests/fixtures/` is a parser/report test input, not a performance or decompilation benchmark. A future benchmark must identify each lawful input by hash, record build/tool versions and compiler flags, define its metric and denominator, and include a reproducible command before results are reported.
